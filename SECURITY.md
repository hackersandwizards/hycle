# Sicherheit

## Eine Schwachstelle melden

Sicherheitsrelevante Probleme bitte über [GitHub Security Advisories](https://github.com/hackersandwizards/hycle/security/advisories/new) melden, nicht über öffentliche Issues.

hycle.org ist eine statische Seite aus HTML und CSS, ohne JavaScript und ohne Backend. Die Angriffsfläche ist klein. Hinweise auf Fehlkonfiguration (Header, DNS, Auslieferung) sind trotzdem willkommen.

Antwortsprachen: Deutsch, Englisch.
